# actl3141assignment

Submitted for ACTL3141 - Modelling and Prediction of Life and Health Related Risks.

The motivation for this task is to investiage the comorbidities and employ survival analysis techniques to hospital patients in Brazil suffering from Covid-19 or Influenza.

An R file accompanies the report which was used to generate all statistical insights and visualisations.
